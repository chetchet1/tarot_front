# 260313-1 수정진행상황

## AdMob 실제 광고 ID 적용

### 작업 내용
- AdMob에서 생성한 실제 광고 유닛 ID로 전체 코드 교체
- 테스트 모드(TEST_MODE) false로 전환

### AdMob ID 정보
| 구분 | ID |
|------|-----|
| 앱 ID | `ca-app-pub-2235114588891951~7392166864` |
| 배너 | `ca-app-pub-2235114588891951/4358809412` |
| 전면(Interstitial) | `ca-app-pub-2235114588891951/8801597247` |
| 보상형(Rewarded) | `ca-app-pub-2235114588891951/3895774984` |

### 수정 파일
1. `app/services/AdService.ts` — Android 광고 ID 교체, 테스트 디바이스 설정 제거
2. `app/config/env.ts` — TEST_MODE=false, ADMOB_CONFIG Android ID 교체
3. `app/services/admob.ts` — adMobConfig 실제 ID + testMode=false
4. `app/services/capacitor/admob.ts` — AD_IDS Android 실제 ID, initializeForTesting=false
5. `android/app/src/main/AndroidManifest.xml` — APPLICATION_ID 실제 앱 ID

### 참고
- iOS ID는 미사용이므로 테스트 ID 유지
- `.env.production`, `.env.android` 파일은 보안 설정으로 수동 수정 필요 (코드 fallback에 실제 ID 있으므로 당장 문제없음)
- 광고 게재 시작까지 최대 1시간 소요 가능 (AdMob 안내)

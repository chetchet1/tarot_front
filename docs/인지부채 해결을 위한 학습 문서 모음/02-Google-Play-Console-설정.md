# Google Play Console 결제 설정

## 1. 구독 상품 등록

### 경로
Google Play Console → 앱 선택 → 수익 창출 → 구독

### 우리 앱 설정
- **상품 ID**: `tarot_sub`
- **이름**: 프리미엄 구독 (사용자에게 보이는 이름)
- **가격**: ₩2,900/월

### 상품 ID란?
- 코드에서 이 상품을 식별하는 고유 문자열
- 한번 만들면 변경 불가 (삭제 후 재생성만 가능)
- Google Play, RevenueCat, 앱 코드 모두 동일한 ID를 사용해야 함

### 베이스 플랜
- 하나의 구독 상품 안에 여러 요금제를 둘 수 있음
- 우리는 `tarot-sub`이라는 베이스 플랜 1개 (월간 ₩2,900)
- 연간, 주간 등 추가 가능

## 2. 결제 프로필

### 경로
Google Play Console → 설정 → 결제 프로필

### 역할
- Google이 개발자에게 수익을 정산할 때 사용
- 은행 계좌, 사업자 정보 등록
- 우리: "조재준" 프로필 연결됨

## 3. 라이선스 테스터

### 경로
Google Play Console → 설정 → 라이선스 테스트

### 역할
- 테스터로 등록된 Google 계정은 **실제 결제 없이** 구독 테스트 가능
- 결제 화면은 나오지만 실제 돈이 빠지지 않음
- 테스트 구독은 빠르게 갱신됨 (1달 → 5분으로 단축)

### 우리 설정
- 16명 등록 ("타로테스터" 목록)
- 비공개 테스트 12명 14일 유지 요건 충족 중

## 4. 비공개 테스트 vs 내부 테스트

| 구분 | 내부 테스트 | 비공개 테스트 |
|------|-----------|-------------|
| **인원** | 최대 100명 | 제한 없음 |
| **승인 대기** | 없음 (즉시) | 검토 필요 |
| **배포 속도** | 몇 분 | 몇 시간~1일 |
| **프로덕션 요건** | 없음 | 12명 × 14일 |
| **용도** | 빠른 개발 테스트 | 프로덕션 전 최종 테스트 |

### 현재 상황
- 비공개 테스트 12명 14일 카운트 진행 중
- 이 조건 충족 후 프로덕션 출시 가능

## 5. Google Play Billing 라이브러리

### 역할
- 앱에서 Google Play 결제 기능을 사용하기 위한 Android 라이브러리
- `android/app/build.gradle`에 선언

### 우리 설정
```gradle
implementation 'com.android.billingclient:billing:7.1.1'
```

### 주의
- Google Play 정책상 **7.0.0 이상** 필수 (2026년 기준)
- 6.2.0 사용 시 정책 위반 경고 발생 → 7.1.1로 업그레이드함

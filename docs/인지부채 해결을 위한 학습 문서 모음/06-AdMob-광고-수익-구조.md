# AdMob 광고 수익 구조

## 광고 수익의 원리

```
광고주 (삼성, 쿠팡 등)
  → Google AdMob에 광고비 지불
  → AdMob이 우리 앱에 광고 노출
  → 사용자가 광고를 보거나 클릭
  → AdMob이 수익의 일부를 우리에게 정산
```

## 우리 앱의 광고 종류 3가지

### 1. 전면 광고 (Interstitial)
- **형태**: 화면 전체를 덮는 광고
- **표시 시점**: 점술 결과를 볼 때 (무료 사용자)
- **사용 파일**: `components/AdModal.vue`, `views/ReadingResult.vue`
- **수익**: 중간 (노출당 $0.5~3)
- **광고 유닛 ID**: `ca-app-pub-2235114588891951/8801597247`

### 2. 보상형 광고 (Rewarded)
- **형태**: 15~30초 동영상 시청 후 보상
- **표시 시점**: 무료 사용자가 프리미엄 배열법 이용 시 "광고 보고 이용하기"
- **사용 파일**: `views/CardDrawing.vue`
- **수익**: 높음 (노출당 $1~10) — 사용자가 끝까지 시청해야 하므로 가치 높음
- **광고 유닛 ID**: `ca-app-pub-2235114588891951/3895774984`

### 3. 배너 광고 (Banner)
- **형태**: 화면 하단에 작은 띠 형태
- **표시 시점**: 게시판 페이지
- **사용 파일**: `views/BoardMain.vue`, `views/BoardPostDetail.vue`
- **수익**: 낮음 (노출당 $0.1~0.5)
- **광고 유닛 ID**: `ca-app-pub-2235114588891951/4358809412`

## 수익 발생 조건

| 조건 | 수익 발생 |
|------|----------|
| 광고 노출 (사용자가 봄) | O (CPM) |
| 광고 클릭 | O (CPC) — 노출보다 수익 높음 |
| 보상형 광고 끝까지 시청 | O (CPV) — 가장 높은 수익 |
| 프리미엄 사용자 | X — 광고 안 보이므로 수익 없음 |

### 수익 모델 용어
- **CPM** (Cost Per Mille): 1,000회 노출당 수익
- **CPC** (Cost Per Click): 클릭당 수익
- **CPV** (Cost Per View): 영상 시청 완료당 수익

## AdMob 앱 ID vs 광고 유닛 ID

```
앱 ID (App ID)
  = 앱 전체에 하나
  = AndroidManifest.xml에 등록
  = ca-app-pub-2235114588891951~7392166864  (물결표 ~)

광고 유닛 ID (Ad Unit ID)
  = 광고 종류마다 하나씩
  = 코드에서 광고 로드할 때 사용
  = ca-app-pub-2235114588891951/8801597247  (슬래시 /)
```

## 코드에서의 광고 ID 위치

| 파일 | 역할 |
|------|------|
| `android/app/src/main/AndroidManifest.xml` | 앱 ID 등록 |
| `app/config/env.ts` | ADMOB_CONFIG (앱 ID + 광고 유닛 ID) |
| `app/services/AdService.ts` | 광고 로드/표시 시 광고 유닛 ID 사용 |
| `app/services/admob.ts` | adMobConfig에 전체 ID 관리 |
| `app/services/capacitor/admob.ts` | Capacitor 플러그인용 ID |

## AdMob 대시보드에서 확인

### 수익 확인
- admob.google.com → 보고서
- 일별/주별/월별 수익 확인 가능
- 광고 유닛별 실적 비교 가능

### 주의사항
- **자기 광고 클릭 금지**: 자기 앱에서 광고를 클릭하면 계정 정지
- **테스터 클릭**: 비공개 테스터가 클릭해도 소량이면 문제 없음
- **새 광고 유닛 활성화**: 생성 후 최대 1시간 걸림
- **수익 정산**: 매월 21일경, $100 이상 누적 시 지급

## 프리미엄 사용자와 광고의 관계

```
무료 사용자:
  → 점술 시 전면 광고 표시
  → 프리미엄 배열법 이용 시 보상형 광고 시청 필요
  → 게시판에 배너 광고 표시
  → 수익: 광고

프리미엄 사용자 (₩2,900/월):
  → 모든 광고 제거
  → 프리미엄 배열법 자유 이용
  → 수익: 구독료
```

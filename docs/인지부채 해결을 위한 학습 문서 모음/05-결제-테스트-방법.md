# 결제 테스트 방법

## 사전 조건

1. 통신판매업 신고 완료 → Google Play Console에 입력
2. 비공개 테스트 빌드 업로드 성공
3. 테스트 기기에 비공개 테스트 앱 설치

## 테스트 종류

### 1. 라이선스 테스터 (무료 테스트)

**설정 위치**: Google Play Console → 설정 → 라이선스 테스트

라이선스 테스터로 등록된 Google 계정으로 결제하면:
- 결제 UI는 정상적으로 표시됨
- **실제 돈이 빠지지 않음**
- 구독 갱신 주기가 단축됨:

| 실제 주기 | 테스트 주기 |
|-----------|-----------|
| 1주일 | 5분 |
| 1개월 | 5분 |
| 3개월 | 10분 |
| 6개월 | 15분 |
| 1년 | 30분 |

### 2. 비공개 테스터 (실제 결제)

비공개 테스트에 참여 중이지만 라이선스 테스터가 아닌 사용자:
- **실제로 결제됨** (₩2,900 차감)
- Google Play 환불 정책에 따라 환불 가능

## 테스트 순서

### Step 1: 앱 설치 확인
- 비공개 테스트 트랙의 앱이 설치되어 있는지 확인
- Google Play → 앱 검색 또는 테스트 초대 링크로 설치

### Step 2: 라이선스 테스터 계정으로 로그인
- 기기의 Google 계정이 라이선스 테스터 목록에 있는지 확인
- 앱에 로그인

### Step 3: 구독 화면 진입
- 설정 → 구독 관리 (또는 프리미엄 기능 접근 시 나타나는 구독 안내)
- 상품 목록이 표시되는지 확인 (₩2,900/월)

### Step 4: 구매 실행
- "구독하기" 클릭
- Google Play 결제 시트가 나타남
- "테스트 카드, 항상 승인" 같은 테스트 결제 수단이 보여야 함
- 결제 완료

### Step 5: 프리미엄 확인
- 구독 완료 후 앱으로 돌아옴
- 광고가 사라지는지 확인
- 프리미엄 배열법(캘틱 크로스, 세븐스타, 컵오브릴레이션십) 접근 가능한지 확인

### Step 6: 해지 테스트
- Google Play → 구독 관리에서 해지
- 현재 기간 끝까지 프리미엄 유지되는지 확인
- 기간 만료 후 프리미엄 해제되는지 확인 (테스트 모드에서 5분)

## 문제 발생 시 확인 사항

### "상품을 찾을 수 없습니다"
- Google Play Console에서 구독 상품이 **활성** 상태인지 확인
- 상품 ID가 코드와 일치하는지 확인 (`tarot_sub`)
- RevenueCat 대시보드에서 상품이 올바르게 등록되었는지 확인

### "결제를 완료할 수 없습니다"
- 라이선스 테스터 목록에 Google 계정이 있는지 확인
- 비공개 테스트 트랙에 올라간 빌드에서만 결제 가능 (내부 테스트 불가)
- billing 라이브러리 버전 확인 (7.0.0 이상)

### "구독했는데 프리미엄이 안 됨"
- RevenueCat 대시보드 → Customers에서 해당 사용자 조회
- entitlements에 `premium`이 활성화되었는지 확인
- 앱 로그에서 DB 저장 성공/실패 여부 확인

## RevenueCat 대시보드에서 확인

### Customers 탭
- 특정 사용자의 구독 상태, 구매 이력 확인 가능
- 사용자 ID (Supabase user ID)로 검색

### Overview 탭
- 전체 매출, 활성 구독자 수, 이탈률 등 대시보드

### Sandbox / Production 전환
- 테스트 구매는 "Sandbox" 환경에서 표시
- 실제 구매는 "Production"에서 표시
- 대시보드 좌측 하단에서 전환 가능
